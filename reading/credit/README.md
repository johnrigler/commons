# Credit reporting as collection pressure

This is the previously prepared Commons credit-bureau explanation, now part
of the website's feed and in-site reader. It covers Equifax, Experian, and
TransUnion, circular verification, fragmented correction, and investigation
duties, with the original primary-source links retained.

The numbered HTML source and PHP assembler produce a self-contained reading
edition. Cross-links return to the corresponding Commons entries. The source
explanation is an unsigned draft authored under John Rigler's direction;
this publication does not add individual case evidence or a ledger transaction.

From this directory, source `~/commons/sb/publish.bash` by absolute path and run
`sb.publish source/page.php` after changing the source. Preserve the old
CID-named file and update the catalog and edition record deliberately.
