F-Droid: another route to Android software

An entry point for free software, with visible sources and fewer commercial dependencies.

F-Droid provides an Android client and a catalog of free and open source applications. Its client needs no account and displays no advertising. It lets you find, install and update apps independently of Google Play. Source availability gives people a way to inspect and modify software; it does not guarantee that every app is secure, compatible, or free of unwanted behavior. Project overview.

Install and use it

  1. Visit f-droid.org on the phone and download its client. Use the official site rather than an APK mirror.
  2. When Android asks, permit the browser to install this downloaded package. Installation permission is specific to the source app; revoke it afterward if you do not need it.
  3. Open F-Droid, let its repository catalog refresh, then search for an app. Review its description, permissions, source link, version and repository before installing.
  4. For this guide, find ShizuCallRecorder. Its package identifier is com.kitsumed.shizucallrecorder. Follow the separate Shizuku setup article.

No ads is a selection rule, not an assumption

The author’s first requirement is no ads. F-Droid is useful for that preference, but its catalog can include apps labeled with advertising or other undesirable properties. Check the Anti-Features labels, including Ads, Tracking and Non-Free Network Services. Extra repositories introduce additional publishers and trust decisions.

The gateway does not manage everything

In the setup that prompted this article, F-Droid supplied the recorder, which directed the user to GitHub for Shizuku. Those are separate installation and update channels. F-Droid does not automatically manage an APK downloaded from GitHub. Repository and upstream builds can differ in version and signing key; do not assume they can replace one another without an uninstall. Export valuable app data before changing channels.
